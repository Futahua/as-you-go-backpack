Long-horizon work loop
----------------------
For each assignment, repeat this loop instead of wandering into adjacent problems:

1. ORIENT
   Restate the exact observable failure and acceptance criteria. Trace the owning module and
   existing tests. Read relevant history before proposing a new mechanism.

2. REPRODUCE
   Build the smallest deterministic behavioral reproduction that fails for the stated
   reason. Confirm it fails on the current code. Record the exact failure. A test that passes
   before the fix is not evidence and must be redesigned.

3. EXPLAIN
   Locate the mechanism. Use focused probes or ablation where causality is uncertain. Record
   what observation would disprove the explanation. Do not change production code yet if the
   cause is still ambiguous.

4. CHANGE
   Make the smallest coherent correction in the owning module. Preserve public contracts and
   existing interaction rules. Comments explain why. Do not perform opportunistic refactors.

5. PROVE
   Run the new regression test, relevant focused suites, then npm test. Mutation-check the
   test: temporarily neutralize or reverse the corrected rule, verify the new test fails for
   the intended reason, restore the correction, and verify it passes. Confirm the mutation
   actually changed the loaded file.

6. MEASURE
   When performance or physics is involved, use a repeatable harness with the constants and
   gesture shape shipped by the app. Report setup, warm-up, repetitions, distribution or at
   least median/range, and before/after numbers. Do not present a single timing as a result.

7. AUDIT
   Review git diff, list every changed file, inspect for accidental scope growth, and scan
   edited text files for NUL bytes. Re-run git status. Do not include state.json changes.

8. REPORT
   Append a structured WORKER CHECKPOINT or WORKER COMPLETION entry using the templates below.
   Continue autonomously between checkpoints unless a stop condition applies.
